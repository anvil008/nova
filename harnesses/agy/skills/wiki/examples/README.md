# Sample namespace

`sample-namespace/` is a wiki namespace for a fictional `checkout-api` project, shipped so
the `Offline demonstration` in [`../SKILL.md`](../SKILL.md) runs against something real
without a store, a repository, or a network. It has three raw bundles, two pattern pages —
one of which has accumulated two dated evidence entries — and a catalog derived from them.

It was generated by the CLI, not written by hand, and it is meant to be **rebuilt** rather
than edited: hand-editing a page or a copied file breaks the sha256 in its manifest or the
counts in `index.md`, which is exactly what `wiki.py check` is there to catch.

To rebuild it, delete the directory and replay the commands below from the repository
root, with `<today>` the current date — raw ids are date-prefixed so a bundle sorts
chronologically, and `wiki.py pattern` dates each evidence entry with the day it ran:

```bash
W="python3 -B skills/wiki/scripts/wiki.py"
NS=skills/wiki/examples/sample-namespace
$W init --namespace "$NS"
$W record --namespace "$NS" --id <today>-build-wave-1 --kind build-wave --summary "..." --file <path> --file <path>
$W pattern flaky-sandbox-lock --namespace "$NS" --evidence <today>-build-wave-1 --note "..."
$W check --namespace "$NS"
```

`project.json` records `source: namespace`, because a namespace addressed directly with
`--namespace` has no repository behind it. A real project's namespace is keyed from its
repository instead; [`../references/wiki-layout.md`](../references/wiki-layout.md) has the
derivation.
