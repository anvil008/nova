# build-guard probe corpus — one probe per line, `expected|command`.
# expected is `allow` or `deny`; everything after the first `|` is the raw shell command.
# test_hooks.sh runs every probe through build-guard for each default payload shape and
# asserts the verdict. An expectation may name one shape instead, as `expected@shape`:
# `claude` / `codex` for a harness's own top-level session, `claude-agent` / `codex-agent`
# for a payload naming the subagent that made the call, `agy` for Antigravity's. Keep the
# deny set to unambiguous policy violations and the allow set to the false positives we
# have actually hit.
