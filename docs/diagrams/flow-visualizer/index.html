Step 1: Micro-TDD in Isolated Workspaces

Saves ~20 Minutes

Specifiers and Builders execute concurrently in isolated jj workspaces. The Builder verifies ONLY its narrow sealed acceptance test (5s) and creates an anonymous local change. No branch is pushed to GitHub, and no intermediate PR is created.

# Builder verifies ONLY its sealed test & commits locally tdd-guard verify --green-command "python3 -m unittest tests/test_token.py" jj describe -m "feat(auth): reject empty API token" # Returns local changeId (e.g. kpqz...) — NO git push, NO PR
