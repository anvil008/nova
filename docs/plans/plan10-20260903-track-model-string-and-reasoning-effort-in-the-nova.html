Track model string and reasoning effort in the Nova Wiki layer

Introduce model string and reasoning effort tracking across the Nova Wiki layer. Extend wiki.py record to accept optional --model and --effort flags and store them in raw/<id>/manifest.json. Extend wiki.py pattern to inspect cited manifests and format citations as <raw-id> [<model>·<effort>] (or [<model>] if effort is null). Update wiki.py check to validate single-line string formatting while preserving 100% backward compatibility for legacy manifests and pattern lines. Document model and effort fields in agents/handoff.md, skills/build/SKILL.md, and skills/review-fix-loop/SKILL.md, and synchronize replicas across all 4 harnesses using scripts/sync-skills.py.

02

Architecture

◇
current + proposed — compare the smallest meaningful system boundary, then state the operational change in plain language.

WikiStoreCLI

Implements record, pattern, and check CLI commands with model and effort tracking and validation in skills/wiki/scripts/wiki.py.

WikiLayoutContract

Defines the specification and schema for manifest.json and pattern page citation formats in skills/wiki/references/wiki-layout.md.

AgentHandoffContract

Specifies optional model and effort fields in dispatch briefs and anvil.agent-handoff/v1 return records in agents/handoff.md.

OrchestratorSkills

Documents passing model and effort parameters during wave acceptance in skills/build/SKILL.md and review-fix-loop exit consolidation in skills/review-fix-loop/SKILL.md.

HarnessReplicas

Maintains synchronized copies of the shared wiki skill across claude, codex, agy, and grok harnesses.

What changes

Enhance the Nova Wiki layer to capture model provenance and reasoning effort alongside recorded evidence bundles and pattern citations. The wiki store records raw trace manifests with optional model and effort properties, automatically includes model and effort tags in pattern page evidence lines, and validates integrity via wiki.py check. The agent handoff contract (agents/handoff.md) and consumer skills (skills/build and skills/review-fix-loop) are updated to propagate model and effort metadata, and harness replicas are synchronized via scripts/sync-skills.py.

Current

Current architecture in words
  • Agent Handoff → wiki.py record (evidence files)
  • wiki.py record → raw manifest (write bundle)
  • raw manifest → wiki.py pattern
  • wiki.py pattern → pattern page (unadorned citation)
  • wiki.py check → raw manifest (verify)
  • wiki.py check → pattern page (verify)

Proposed

Proposed architecture in words
  • Agent Handoff with model and effort → wiki.py record (--model and --effort)
  • wiki.py record → raw manifest with metadata (store model and effort)
  • raw manifest with metadata → wiki.py pattern (inspect metadata)
  • wiki.py pattern → pattern page with bracketed tags (model and effort citation)
  • wiki.py check → raw manifest with metadata (validate sanitized strings)
  • wiki.py check → pattern page with bracketed tags (validate citation tags)
