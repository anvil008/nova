swarm-coder — Solution implementation plan

Foreign-provider swarm-runplane jobs can run in one dedicated non-focused Herdr 0.8.2 tab/root pane with safe task context, authenticated bounded worker control, exact provider streams, deterministic visibility replay, and unchanged validated handoff/workflow-result authority; same-provider native harness agents remain explicitly unsupported.

Success measures
  • Every eligible foreign job is independently watchable in a distinct non-focused pane while direct mode remains compatible.
  • Only taskRef, task, phase, summary, model, and attempt are published, within bounds and without briefs, credentials, nonces, provider input, or pane IDs.
  • The per-job mode-0600 channel preserves exact streams, ordered input acknowledgements, bounded reconnect, cancellation, recovery, and validated terminal result authority.
  • Visibility metadata errors never alter Job.Status or workflow disposition; worker or pane loss is reported as a transport failure.
  • Provider-free focused, race, combined package, and offline conformance commands pass without live Herdr configuration mutation or provider/model calls.
Assumptions
  • Herdr 0.8.2 is the supported contract for this repository-only slice.
  • The pre-existing dirty worktree is user-owned and all overlapping bytes must be adopted in place rather than restored from Git.
  • Nexus board import is intentionally not authorized in this execution lane, so every board_task_ref remains null and delivery import_status remains pending.
  • The public run-plane API remains additive anvil.run-plane/v2 while on-disk state migrates from schema 2 to schema 3.
Global invariants
  • Validated anvil.agent-handoff/v1 and controlplane.WorkflowResult records remain the only terminal work authority; Herdr is non-authoritative presentation.
  • Herdr pane and agent IDs are volatile locators and never appear in task, run, dispatch, generation, or attempt identifiers.
  • Activation requires HERDR_ENV=1 plus an explicitly injected absolute HERDR_BIN_PATH, socket or named session, and workspace; ambient PATH, focused UI, --current, and live config mutation are forbidden.
  • Briefs, tokens, bearer credentials, claim nonces, raw prompts, and provider input remain off argv and out of display metadata.
  • Cancellation signals only the provider process group; it never kills the pane shell, closes the pane, or stops a Herdr session.
  • Completed panes remain open, and visibility failures cannot change durable job status or workflow disposition.
  • No live Herdr config edit or reload, build install, deployment, model/provider call, commit, push, external message, destructive action, or Nexus import is authorized.
Out of scope
  • Same-provider native Codex, Claude, or Antigravity harness adapter support.
  • Public arbitrary display-metadata mutation endpoints or MCP tool expansion.
  • Automatic pane closure, session shutdown, config reload, installation, deployment, or production rollout.
  • Using report-agent to synthesize lifecycle or treating pane liveness as completion evidence.
