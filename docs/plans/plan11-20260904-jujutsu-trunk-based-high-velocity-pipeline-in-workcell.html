Jujutsu Trunk-Based High-Velocity Pipeline in Workcell

Implement the Jujutsu trunk-based high-velocity pipeline in Workcell. Transition the build lifecycle from an intermediate GitHub PR model to true Jujutsu (jj) trunk-based development with zero network roundtrip local handoffs and single remote CI gating. Update agents/handoff.md to formally specify local changeId handoff in anvil.agent-handoff/v1. Update agents/bodies/builder.md and agents/bodies/integrator.md to restrict builder verification strictly to sealed acceptance tests (~5s), eliminate intermediate GitHub branch pushes and PR creation, and empower the integrator to instantly combine wave changes onto the integration trunk in ~50ms via jj rebase -s <changeId> -d <integration-trunk> and execute the full test suite (scripts/run-tests.sh + linters) once on the combined wave state. Update .github/workflows/ci.yml to add Go build cache (~/.cache/go-build) and Python pip dependency caching, accelerating remote CI runs from ~3.5m to ~1m. Update skills/build/SKILL.md and skills/build/tests/test_build.py to codify trunk-based wave integration and builder test scoping while maintaining 100% of wave-loop and single-PR invariant assertions. Synchronize updated skills and agent definitions across all 4 harness replicas (claude, codex, agy, grok) via scripts/sync-skills.py and scripts/sync-agents.py.

Architecture

◇
current + proposed — compare the smallest meaningful system boundary, then state the operational change in plain language.

AgentHandoffContract

Specifies local changeId handoff and null PR semantics for trunk-based development in agents/handoff.md.

AgentLifecycleBodies

Defines strict test scoping, local jj describe commits, and jj rebase wave integration in agents/bodies/builder.md and agents/bodies/integrator.md.

CIWorkflowAcceleration

Provides Go build cache and Python pip dependency caching in .github/workflows/ci.yml with main-branch-scoped remote CI execution.

BuildSkillTrunkPipeline

Codifies single remote CI gating, local jj rebase wave integration, and builder test scoping in skills/build/SKILL.md and tests.

HarnessReplicas

Propagates updated build skill and agent definitions across claude, codex, agy, and grok harness replicas using sync scripts.

What changes

Transition Workcell from per-issue GitHub PR pushes and remote CI bottlenecks to Jujutsu trunk-based development with single remote CI gating. Builders verify strictly scoped sealed acceptance tests in isolated jj workspaces, commit locally, and hand off anonymous change IDs. Integrators rebase wave changes locally in 50ms and execute the full project test suite once. Only the final milestone PR to main is pushed to GitHub, gated by an accelerated, cached GitHub Actions CI workflow.

Current

Current architecture in words
  • Specifier: tdd-guard seal → Builder: Broad discovery tests (116s)
  • Builder: Broad discovery tests (116s) → jj git push bookmark to remote
  • jj git push bookmark to remote → gh pr create intermediate PR
  • gh pr create intermediate PR → gh pr checks --watch (4m stall per PR)
  • gh pr checks --watch (4m stall per PR) → Integrator: gh pr merge --rebase per PR
  • Integrator: gh pr merge --rebase per PR → Full project test suite repeated serially
  • Full project test suite repeated serially → Final PR to main
  • Final PR to main → GitHub Actions CI (6th run, 24 remote jobs)
  • GitHub Actions CI (6th run, 24 remote jobs) → Trunk / main branch
  • Wave Execution (Previous Multi-PR Flow) groups: Specifier: tdd-guard seal, Builder: Broad discovery tests (116s), jj git push bookmark to remote, gh pr create intermediate PR, gh pr checks --watch (4m stall per PR), Integrator: gh pr merge --rebase per PR

Proposed

Proposed architecture in words
  • Specifier: tdd-guard seal RED (15s) → Builder: Scoped sealed test only (5s)
  • Builder: Scoped sealed test only (5s) → jj describe local commit (no push)
  • jj describe local commit (no push) → anvil.agent-handoff/v1 with changeId (50ms)
  • anvil.agent-handoff/v1 with changeId (50ms) → Integrator: jj rebase -s changeId -d integration-trunk (50ms)
  • Integrator: jj rebase -s changeId -d integration-trunk (50ms) → Single consolidated test gate (scripts/run-tests.sh, 1x)
  • Single consolidated test gate (scripts/run-tests.sh, 1x) → Single milestone PR to main (Closes #)
  • Single milestone PR to main (Closes #) → GitHub Actions CI (1x run with Go & Pip Caching ~1m)
  • GitHub Actions CI (1x run with Go & Pip Caching ~1m) → Trunk / main branch
  • Wave Execution (Jujutsu Trunk Flow) groups: Specifier: tdd-guard seal RED (15s), Builder: Scoped sealed test only (5s), jj describe local commit (no push), anvil.agent-handoff/v1 with changeId (50ms), Integrator: jj rebase -s changeId -d integration-trunk (50ms)
